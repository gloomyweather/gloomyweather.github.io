# gloomyweather.github.io

my home page: [gloomyweather.github.io](https://gloomyweather.github.io).

plain html, css and two small vanilla scripts: `script.js` (animations, keys, palette, rain, theme) and `demo.js` (the live todoterm and jot windows, saved in your browser only). no build step, no dependencies. edit `index.html`, push, done.
the terminal pictures are text captures of the real apps (todoterm, jot). `ember.webp` is four of the theme's wallpapers, `mono.webp` is a screenshot of the mono desktop.
the font is [jetbrains mono](https://www.jetbrains.com/lp/mono/) 2.304, served from `fonts/` (ofl, see `fonts/OFL.txt`).
