# gloomyweather.github.io

my home page: [gloomyweather.github.io](https://gloomyweather.github.io).

plain html and css, no build step, no scripts. edit `index.html`, push, done.
the terminal pictures are text captures of the real apps (todoterm, jot). `ember.webp` is four of the theme's wallpapers, `mono.webp` is neovim on the mono desktop.
the font is [jetbrains mono](https://www.jetbrains.com/lp/mono/) 2.304, served from `fonts/` (ofl, see `fonts/OFL.txt`).
