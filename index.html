gloomyweather

small, quiet tools for the terminal and omarchy.

each one does one thing and stays out of the way. all of them run on linux and plug into omarchy: a hotkey, the launcher, the bar, the current theme.

  1. 01omarchy-gdrivegoogle drive as a normal folder on omarchy.
  2. 02todoterma minimalist task manager for the terminal.
  3. 03jotquick notes for the terminal.
  4. 04embera black-and-white omarchy theme with one orange accent.
  5. 05monoa grayscale omarchy theme with real colors in the terminal.

omarchy

plugins, apps and themes for omarchy.

01omarchy-gdrive

google drive as a normal folder on omarchy.

  • open, edit and save drive files from files, the terminal or any app. built on rclone.
  • bookmarks in files, right-click to open in google drive or make available offline, a drive icon in the bar, an entry in the omarchy menu.
  • super + ctrl + g opens drive.
  • runs only on your computer and talks only to google. needs omarchy 4 and your own google key (about ten minutes, once).
git clone https://github.com/gloomyweather/omarchy-gdrive-app.git \
  ~/.local/src/omarchy-gdrive
~/.local/src/omarchy-gdrive/install.sh

02todoterm૮ ˶ᵔ ᵕ ᵔ˶ ა

a minimalist task manager for the terminal.

  • one window, one list. vim-like keys, priorities and due dates right in the text: buy milk !! @fri.
  • super + alt + t opens it in a floating window, or focuses it if it's already open.
  • follows the current omarchy theme and repaints live when you switch themes.
  • saves after every change, atomically. a broken todo.json is never overwritten.
git clone https://github.com/gloomyweather/todoterm
cd todoterm
contrib/omarchy/install.sh

03jot◆

quick notes for the terminal.

  • a list on the left, the rendered note on the right, an editor one key away.
  • notes are plain markdown files in ~/Notes, one file per note. edit them with anything, sync them with anything.
  • super + alt + n opens notes. super + ctrl + alt + n opens a quick note; esc saves and closes it.
  • floats and follows the current omarchy theme live. jot add "buy milk" saves a note without opening anything.
git clone https://github.com/gloomyweather/jot
cd jot
contrib/omarchy/install.sh

04ember◐

a black-and-white omarchy theme with one orange accent.

  • pure black, pure white and #d97757. window borders, the bar and the keywords in your editor all burn the same quiet orange.
  • a dark and a light version. switch between them like any omarchy theme.
  • twelve wallpapers each: a soft glow, thin rings, a striped sun, a lora ampersand, a few quiet quotes. drawn by a script, not downloaded.
  • an orange boot and unlock logo to match.
omarchy theme install https://github.com/gloomyweather/omarchy-ember-theme
omarchy theme install https://github.com/gloomyweather/omarchy-ember-light-theme
omarchy theme set ember

05mono▒

a grayscale omarchy theme with real colors in the terminal.

  • the desktop is graphite and gray: window borders, the bar, menus, notifications, the lock screen. alerts show in white instead of red.
  • the terminal and neovim keep a real palette, carbonfox, with a proper yellow. code and diffs read the way they should.
  • six wallpapers: a soft glow, thin rings, a fading grid, contour lines, a horizon, plain grain. drawn by a script, not downloaded.
  • a light gray boot and unlock logo to match.
omarchy theme install https://github.com/gloomyweather/omarchy-mono-theme
omarchy theme set mono
