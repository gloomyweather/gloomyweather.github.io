01omarchy-gdrive

google drive as a normal folder on omarchy.

  • open, edit and save drive files from files, the terminal or any app. built on rclone.
  • bookmarks in files, right-click to open in google drive or make available offline, a drive icon in the bar, an entry in the omarchy menu.
  • super + ctrl + g opens drive.
  • runs only on your computer and talks only to google. needs omarchy 4 and your own google key (about ten minutes, once).
git clone https://github.com/gloomyweather/omarchy-gdrive-app.git \
  ~/.local/src/omarchy-gdrive
~/.local/src/omarchy-gdrive/install.sh

02todoterm૮ ˶ᵔ ᵕ ᵔ˶ ა

a minimalist task manager for the terminal.

  • one window, one list. vim-like keys, priorities and due dates right in the text: buy milk !! @fri.
  • super + alt + t opens it in a floating window, or focuses it if it's already open.
  • follows the current omarchy theme and repaints live when you switch themes.
  • saves after every change, atomically. a broken todo.json is never overwritten.
git clone https://github.com/gloomyweather/todoterm
cd todoterm
contrib/omarchy/install.sh

03jot◆

quick notes for the terminal.

  • a list on the left, the rendered note on the right, an editor one key away.
  • notes are plain markdown files in ~/Notes, one file per note. edit them with anything, sync them with anything.
  • super + alt + n opens notes. super + ctrl + alt + n opens a quick note; esc saves and closes it.
  • floats and follows the current omarchy theme live. jot add "buy milk" saves a note without opening anything.
git clone https://github.com/gloomyweather/jot
cd jot
contrib/omarchy/install.sh

04mdterm

a vim-like markdown editor and viewer for the terminal.

  • raw markdown on the left, a live preview on the right.
  • normal, insert and visual modes, : commands, several files open at once.
  • syntax highlighting for code blocks in the preview. large files stay fast.
git clone https://github.com/gloomyweather/mdterm
cd mdterm
cargo install --path .
